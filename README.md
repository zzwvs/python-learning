# 🐍 Python 学习仓库





`大一新生开学前的 Python 自学成果记录与代码练习。`

`这是一个记录我个人 Python 学习旅程的仓库。在大一开学前，我利用空闲时间系统学习了 Python 基础知识，并将学习笔记、课后练习以及实战项目统一推送至此，作为我的编程入门档案。`





## 🚀 如何运行

1. `克隆仓库到本地
   bash
   git clone https://github.com/你的用户名/Python-学习.git`

2. `进入仓库目录
   bash
   cd Python-学习`

3. `运行指定的 Python 文件
   bash
   python 学习笔记.py`
